# Academic Project Requirements & Viva Explanation Guide

## Problem Statement
"AI-Powered IT Service Management and Incident Resolution Platform (IT Operations)"

## Key Highlights for Viva Presentation
1. **Multi-tier Decoupled Architecture**: Frontend (React/Vite/TS), Backend (FastAPI/SQLAlchemy), AI Engine (Mock/LLM Interface), Database (PostgreSQL).
2. **Enterprise RBAC**: Role-Based Access Control supporting 7 distinct roles (Super Admin, IT Manager, Service Desk Agent, IT Support Engineer, Infrastructure Engineer, Change Manager, End User).
3. **18 Functional ITSM Modules**: Comprehensive coverage from Incident Management to AI Analysis, SLA tracking, and Infrastructure Monitoring.
4. **AI Ready Design**: Pluggable AI service interface allowing instant upgrade from mock responses to live LLM API endpoints (OpenAI, Gemini, Claude).
